# Medical-Tool-Container-Design
This project involved designing a special container for a medical tool that could be securely transported and sterilized using an automated robotic system. The project consisted of two sub-teams working together: a modelling sub-team (which I was apart of) responsible for designing the container and a computing sub-team responsible for programming a robotic arm to move the container into an autoclave.

## Project Objectives

The modelling sub-team was responsible for:
- Designing a lightweight container with an easy-to-grip base
- Securely holding the assigned medical tool
- Ensuring the container could be held by the robotic arm

#Design Requirements & Constraints

The container had to meet several design requirements:
- Fit within the required footprint
- Not exceed the Q-Arm's claw width
- Have features that were at least 2 mm in size
- Have a 3D printing time of 2 hours or less

#Design Development

I contributed to the early design process by brainstorming possible container designs and creating a rough sketch to communicate the initial concept.

#Final Container Design

The final container was designed to mirror the shape of the assigned medical tool while meeting the project requirements.

Key design features included:
- Multiple holes to support effective sterilization
- Two side holes for securing the tool with pins
- Ledges to help the Q-Arm grip the container

#Key Takeaways
This project taught me the importance of addressing disagreements quickly and communicating effectively with teammates. A disagreement over the shape of the container caused delays, which showed me how important it is to find a compromise while keeping the project's main objectives in mind.

The project also taught me the importance of adapting a design when problems arise during testing. The pins used to secure the medical tool would fall out while working with the Q-Arm. Looking back, a lid could have provided a more reliable way to secure the tool.

Overall, this project strengthened my ability to contribute to an engineering design while coordinating with teammates and adapting to challenges during the development process.
